## 🚀 Panoramica
SSH Manager Pro è progettato per semplificare la gestione delle sessioni SSH, garantendo un'esperienza fluida e veloce.

## 📦 Installazione
Scarica l'ultima versione dalla sezione **Releases** o usa il terminale:

```bash
git clone https://github.com/linux07source/ssh-manager-pro.git
cd ssh-manager-pro
sudo dpkg -i pacchetto_ssh.deb
alias ssh-pro='/usr/local/bin/ssh_manager_pro'
source ~/.zshrc || source ~/.bashrc
ssh-pro || ssh_manager_pro
```
## 📦 Disinstallazione
Vuoi cancellare l'app? Esegui questo comando
```bash
sudo apt remove ssh-manager-pro
```
